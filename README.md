## 🚀 Why git.gay?

This has happened before — more than once. Here is the full story:

- The project that came before StreamFlix Reborn was already hit with a DMCA takedown on GitHub.
- The **first StreamFlix Reborn** account was then **banned by GitHub without any warning, email, or explanation** of any kind.
- A **second account** (streamflix-reborn2) was created to continue the project. That repository was then hit with a **DMCA takedown**.

Enough is enough. At this point it is clear that GitHub is not a safe or reliable home for this project.

We decided to permanently move to **[git.gay](https://git.gay)** — an independent, community-run platform based on [Forgejo](https://forgejo.org/), an open source fork of Gitea, where we are no longer at the mercy of GitHub's opaque moderation.

Here's why:

- **Independent from Microsoft/GitHub** — no more risk of opaque account bans or aggressive corporate enforcement.
- **Open source and community-driven** — git.gay is run by a community that values privacy and software freedom.
- **More control** — our code is hosted on a platform that aligns with open source values.
- **Privacy-first** — no tracking by big tech companies.
